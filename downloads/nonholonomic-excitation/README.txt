Full-rate nonholonomic illustration data

Download all 7 numbered parts and join_data.py into one folder, then run:
python join_data.py

The resulting simulation.npz contains the original float64 trace, inputs, potentials,
and configuration. The record retains 100 samples per oscillator cycle.
No samples were removed and no numerical values were rounded for hosting.
